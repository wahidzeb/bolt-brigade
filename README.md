# Bolt Brigade by Zaib

A family-friendly shoot-and-hide cover shooter: hold to pop out and auto-fire at wind-up toy robots, let go to duck and reload. 35 missions across 5 stages, 5 bosses, blaster upgrades. Single self-contained `index.html` (canvas, WebAudio, no libraries).

**Play:** https://zaibgames.com/bolt-brigade/

Game by Zaib.
